# Personajes-Cedenorte

🚀 **¡MISION GIT & GITHUB DE HOY!** 🚀

¡Hola gente! Hoy toca liderar la primera parte de la clase y vamos a armar el **Multiverso de Cedenorte** 🎓. La idea es subir un personaje cómico a nuestro repositorio en GitHub usando ramas y Pull Requests.

---

🎲 **Paso 0: Las Ruletas**
Antes de empezar, giraremos las ruletas para asignar:

1. **La persona inspiradora** (compañero, profe o famoso).
2. **El rol de tu personaje** (Héroe, Héroe sin poderes, Villano tonto, Villano, Chismoso del salón, conspiranoico, el fantasma, el impostor, etc.).

---

💻 **Paso a Paso en Git:**

1. **Clona el repo:**
`git clone <URL_DEL_REPO>`
2. **Crea tu rama desde `develop`:**
`git checkout develop`
`git checkout -b feature/tu-nombre`
3. **Crea tu personaje:**
* Ve a la carpeta `/personajes/`.
* Copia el archivo `plantilla.html` y renómbralo con tu nombre (ejemplo: `juan_perez.html`).
* Abre tu nuevo archivo y llena los datos: foto (ruta de la foto guardada en la carpeta), tu rol, en quién te inspiraste y tu historia chistosa relacionada con Cedenorte.


4. **Sube tus cambios:**
`git add .`
`git commit -m "Añadido personaje de TuNombre"`
`git push origin feature/tu-nombre`
5. **Haz tu Pull Request (PR):**
* Ve a GitHub y abre el Pull Request **apuntando a la rama `develop**` (¡no a `main`!).
* El encargado de la Rama Develop se encarga de revisar y aceptar el Pull Request. Cuando haga este proceso con todos, el Develop hace Pull Request a la rama Release.
* El encargado de la rama Release se encarga de que todo funcione, posterior a esto, acepta el Pull Request, y miramos el resultado

---

🔥 **Al final leemos las historias de todos, vamos a ver quién nos hace reir más.**

*Nota: Cualquier duda o si les sale un conflicto raro de Git, avísenme y lo resolvemos juntos.* ¡A programar! 🤓💻
